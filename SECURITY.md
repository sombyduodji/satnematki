# Security

Sátnemátki is a static web game for children: plain HTML, JavaScript, pictures and sounds, with no server code, no accounts
and no data sent anywhere. Player names and progress stay in the browser's own storage on the device.

If you find a security or privacy problem, please tell us privately by e-mail to **satni@somby.fi** instead of opening a public
issue. Say what you found and how to see it. We'll answer as soon as we can.

Only the latest published version is maintained.
